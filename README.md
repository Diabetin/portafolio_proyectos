# Portafolio de proyectos – Alexander Acosta

Este repositorio reúne proyectos desarrollados en contextos de formación y trabajo, incluyendo Talento Digital (Django + SQL) y módulos para Odoo SH.

## Contenido
- **Eccomerce_M7**  
  E-commerce desarrollado como proyecto de Talento Digital. Incluye CRUD de productos y autenticación de usuarios.

- **Nebula Shop (Django)**  
  E-commerce desarrollado como proyecto de Talento Digital. Incluye gestión básica de carrito de compras.

- **Módulos Odoo (Odoo SH)**  
  Desarrollo y personalización de módulos para Odoo, enfocados en la automatización de procesos de negocio.

- **PDLA_AI (Django)**  
  Plataforma y herramientas basadas en Django para el procesamiento, conversión y extracción de datos.

- **GalaxyWatchCameraBridge (Android & Wear OS)**  
  Aplicación puente desarrollada en Kotlin para conectar dispositivos Android con relojes inteligentes Galaxy Watch. Permite transmisión de video fluido (60 FPS) y audio a través de redes locales (TCP/LAN), recortes dinámicos en pantalla circular (1:1), control remoto de cámara y fallback automático a Bluetooth.

## Tecnologías principales

- Python, Django, Odoo
- Kotlin, Android, Wear OS (CameraX, Wearable Data Layer)
- PostgreSQL, SQL
- HTML, CSS, Bootstrap, JavaScript, XML
- Git y GitHub
